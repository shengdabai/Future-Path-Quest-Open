# 版本设计与审查记录

## 背景

目标不是做一张静态职业榜单，而是搭建一个“通往未来的发展路径游戏”：用户在真实人生约束中选择专业、职业、学习任务、社交行动、赚钱方式、投资纪律和消费策略。

## 多版本方案

| 版本 | 产品形态 | 主要玩法 | 优点 | 风险 |
|---|---|---|---|---|
| A 战略地图版 | 个人发展驾驶舱 | 选择目标，拆资源、风险、作品、收入 | 方向清楚，适合复盘 | 容易像报告，不够好玩 |
| B RPG 闯关版 | 等级任务游戏 | Lv.1 到 Lv.10，任务、事件、解锁 | 行动感强，容易坚持 | 可能过度游戏化 |
| C 人生沙盒版 | 每周选择模拟器 | 学习、作品、社交、赚钱、投资、消费、休息取舍 | 最贴近现实 | 初期复杂度较高 |
| 最终执行版 | 混合版 | 战略定方向，RPG 推进，沙盒训练取舍 | 最符合“学习和成长”的目标 | 后续需要 AI 教练增强反馈 |

## 本轮增强

| 模块 | 作用 | 当前实现 |
|---|---|---|
| AI 教练复盘 | 每 4 周总结节奏、瓶颈、偏差和下一步 | 基于最近 4 次行动、当前状态、职业证明和关卡任务生成 |
| 30 天冲刺 | 把复盘转成未来 4 周计划 | 自动生成第 1-4 周任务 |
| 作品资产 | 把职业要求转成证据清单 | 点击“添加本周证据”沉淀作品记录 |
| 赚钱模型 | 把能力包装成服务包 | 入门诊断包、两周作品冲刺、月度增长顾问，支持模拟成交 |
| 更佳路线 | 把职业选择压缩成 90 天可执行路径 | 根据目标职业、最低资源和证据缺口动态生成 |
| 本周作战台 | 把复杂系统压缩成本周一个焦点 | 根据最低资源、证据缺口、目标职业和 XP 动态生成 |
| 家庭决策卡 | 让学生和家长能一起判断方向 | 展示学生自测、家长视角、30 天验证和换路信号 |
| 进度导入恢复 | 让本地存档可迁移 | 复制 JSON 后可粘贴导入恢复 |
| 作品证据表单 | 让作品资产接近真实作品集 | 支持标题、URL、状态和反馈摘要 |
| 验证增强 | 防止 DOM 和脚本脱节 | 自动检查新增 DOM id 和 `app.js` 的 `$()` 引用 |
| 状态迁移 | 保护旧版本进度 | 旧存档自动补齐 schema、history、画像和数值范围 |

## 风险与回滚

| 风险 | 控制方式 |
|---|---|
| 就业数据随时间变化 | 数据文件带 `asOf`，后续只需更新 `data/future-pathways.json` |
| 浏览器 file 模式拦截 JSON | 生成 `data/future-pathways.js`，直接打开也能运行 |
| 推荐被误解为确定答案 | README 和数据源说明明确这是规划模型，不是保证 |
| 本地进度丢失 | 可用导出按钮复制进度 JSON |
| 导入 JSON 被污染 | 导入时走 `normalizeState()`，非法字段回退默认值 |
| 用户把模拟收入当真实收入 | UI 和 README 保持“模拟成交”表述 |
