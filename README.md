# 未来路径闯关系统

一个可直接打开的游戏化职业发展系统：根据真实就业需求，筛选未来 10 个专业选择和 10 个职业角色，并把学习、社交、赚钱、投资、消费、恢复等人生场景做成闯关模拟。

## 背景

系统基于两个主要事实源：

| 来源 | 用途 |
|---|---|
| U.S. Bureau of Labor Statistics Employment Projections 2024-2034 | 判断职业增长、岗位数量、薪资和刚需程度 |
| World Economic Forum Future of Jobs Report 2025 | 判断 2030 前技能变化、AI/数据/网络安全/绿色转型/照护/教育趋势 |

## 需求

| 类型 | 内容 |
|---|---|
| Must | 筛选 10 个未来专业和 10 个职业角色 |
| Must | 根据个人画像动态调整排序 |
| Must | 设计闯关升级路径 |
| Must | 加入学习、社交、赚钱、投资、消费、能量恢复 |
| Must | 加入 AI 教练 4 周复盘和下一步行动建议 |
| Must | 加入作品资产和服务包报价模拟 |
| Must | 加入更佳发展路线建议 |
| Must | 加入本周作战台、家庭决策卡和进度导入恢复 |
| Must | 可直接打开使用，不依赖安装 |
| Should | 保存进度，支持导出 |
| Should | 作品资产支持链接、状态和反馈 |
| Should | 提供多版本方案并选择最终版 |
| Could | 未来接入真实 API、账号体系、多人社群 |
| Won't | 当前版本不做真实金融建议、不做真实学校申请替代、不做在线后端 |

## 方案

最终采用 A+B+C 混合方案：

| 版本 | 核心 | 取舍 |
|---|---|---|
| A 战略地图版 | 管理目标、资源、风险、作品、收入和资本 | 适合长期规划，但游戏感弱 |
| B RPG 闯关版 | 等级、任务、随机事件、解锁奖励 | 行动驱动强，但容易简化现实 |
| C 人生沙盒版 | 每周做学习、作品、社交、赚钱、投资、消费、恢复的取舍 | 贴近现实，但需要清晰目标 |
| 最终版 | 战略方向 + RPG 任务 + 人生沙盒 | 既能规划，也能每天推进 |

## 运行方式

直接双击打开：

```text
./index.html
```

也可以启动本地服务器：

```bash
cd future-path-quest-open
npm run start
```

然后打开：

```text
http://localhost:8787/
```

## 测试方式

```bash
cd future-path-quest-open
npm run build:data
npm run validate
npm run check
npm i -D playwright && npx playwright install chromium && npm run smoke   # 浏览器冒烟测试（可选）
```

端口被占用时，可以换端口启动服务，并用 `BASE_URL` 指向新的地址：

```bash
python3 -m http.server 8877
BASE_URL=http://localhost:8877/ npm run smoke
BASE_URL=http://localhost:8877/ npm run screenshot
```

## 已知限制

| 限制 | 说明 |
|---|---|
| 非个性化深度咨询 | 当前画像只有轻量输入，不能替代真实升学、求职、职业咨询 |
| 数据源有限 | 主要参考美国 BLS 和 WEF 全球趋势，未来可加入中国/行业招聘数据 |
| 无后端同步 | 进度存在浏览器 localStorage，换浏览器不会同步 |
| 非金融建议 | 投资模块用于训练纪律和风险意识，不构成投资建议 |
| 非真实收款 | 服务包报价是商业模拟，不会发起真实支付 |

## 本轮升级

| 模块 | 提升 |

| 本周作战台 | 根据最低资源、当前职业、证据缺口和 XP 生成本周焦点 |

| 验证增强 | smoke test 覆盖证据表单、导入恢复、家庭决策卡和收入恢复 |
